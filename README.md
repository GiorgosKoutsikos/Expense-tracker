# Expense Tracker (CLI)

A lightweight and interactive Command-Line Interface (CLI) application for recording and tracking personal expenses, built with Python and SQLite.

## About This Project

This project was developed for **learning purposes** as part of hands-on practice with core Python concepts, relational database management using SQLite, and professional Git version control habits.

## Features

- **SQLite Storage:** Automatic initialization and management of a local database (`expenses.db`).
- **Add Expenses:** Store expense descriptions and amounts safely using parameterized SQL queries.
- **View Expenses:** Retrieve and display all recorded expenses directly in the console.
- **Interactive Menu:** Simple, looped terminal menu for seamless navigation.

## What I Learned

- Interacting with embedded relational databases via Python's built-in `sqlite3` library.
- Executing parameterized queries (`?`) to prevent SQL injection vulnerabilities.
- Designing clean CLI execution flow with functions and interactive control loops.
- Managing local databases and tracking progress using modular Git commits and `.gitignore`.
